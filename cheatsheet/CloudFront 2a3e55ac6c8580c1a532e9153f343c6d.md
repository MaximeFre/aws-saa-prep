---

## 🧭 **Purpose**

**Amazon CloudFront** is a **global Content Delivery Network (CDN)** that delivers data, videos, APIs, and applications securely with **low latency** and **high transfer speeds** using **AWS edge locations** around the world.

It integrates with many AWS services (e.g., S3, ALB, API Gateway, Shield, and WAF) to accelerate content and protect applications.

---

## ⚙️ **Key Features**

| Feature | Description |
| --- | --- |
| **Edge Locations** | Global network of PoPs (Points of Presence) for caching content closer to users. |
| **Origin Sources** | Any HTTP endpoint (commonly **S3**, **ALB**, or **EC2**) that provides original content. |
| **Caching & TTLs** | Cache static and dynamic content; customize caching behavior with **Cache-Control headers** or **behaviors**. |
| **Origin Access Control (OAC)** | Securely restrict S3 access to CloudFront (replaces OAI). |
| **Field-Level Encryption** | Encrypt specific data fields at the edge before reaching origins. |
| **Geo Restriction** | Allow or block content delivery based on viewer location. |
| **Lambda@Edge** | Run serverless code at edge locations to customize responses or headers. |
| **CloudFront Functions** | Lightweight, ultra-fast request/response manipulation (cheaper than Lambda@Edge). |
| **Origin Failover** | Configure multiple origins for redundancy (e.g., primary S3 + secondary ALB). |
| **HTTPS Everywhere** | Enforce SSL/TLS between clients and CloudFront or CloudFront and origin. |
| **Signed URLs / Cookies** | Restrict access to private content. |
| **Integration with Shield & WAF** | Built-in DDoS protection and web-layer security. |

---

## 🏗️ **Common Exam Use Cases**

| Scenario | Recommended Solution |
| --- | --- |
| Deliver global static website content with low latency | Use **CloudFront + S3 (static hosting)** |
| Protect S3 bucket from direct access | Use **Origin Access Control (OAC)** or **OAI** |
| Accelerate API responses globally | Use **CloudFront + API Gateway or ALB** |
| Apply logic to requests at the edge (e.g., header rewrite) | Use **CloudFront Functions** or **Lambda@Edge** |
| Serve content securely to specific users | Use **Signed URLs or Signed Cookies** |
| Ensure content availability across multiple origins | Configure **Origin Failover** |
| Comply with regional restrictions | Use **Geo Restriction** settings |
| Protect app from DDoS and web exploits | Enable **AWS Shield Standard** and **AWS WAF** |
| Optimize performance for video streaming | Use **RTMP or HTTP Live Streaming (HLS)** via CloudFront |
| Provide private content delivery via VPN/VPC | Use **Private Origin + OAC** with custom headers |

## 🔐 **Security Considerations**

- Use **Origin Access Control (OAC)** (preferred) or **Origin Access Identity (OAI)** for private S3 origins.
- Enforce **HTTPS-only connections**.
- Restrict content using **Signed URLs or Cookies**.
- Enable **AWS WAF** for web app protection.
- **Shield Standard** (included) defends against DDoS; **Shield Advanced** adds extra reporting and response.
- Use **Field-Level Encryption** for sensitive data fields (e.g., PII).
- Log access via **CloudFront Access Logs** or **Real-Time Logs** to S3/Kinesis.

---

## 💲 **Pricing Model**

- Pay for:
    - **Data transfer out** (varies by region)
    - **HTTP/HTTPS requests**
    - **Invalidation requests** (first 1,000/month free)
    - **Field-Level Encryption** and **Real-Time Logs** (optional cost)
- **No additional cost** for integration with AWS Shield Standard.
- **Cheaper edge delivery** compared to direct S3 or EC2 distribution at scale.

---

## 🔗 **Integration Patterns**

- **S3** → Static website origin (with OAC).
- **ALB / EC2** → Dynamic origin for APIs or web apps.
- **API Gateway** → Global API acceleration.
- **Lambda@Edge / CloudFront Functions** → Edge-side logic and request customization.
- **AWS WAF & Shield** → Security protection.
- **ACM** → Free custom SSL certificates for HTTPS endpoints.
- **CloudWatch & Kinesis** → Monitoring and log streaming.

---

## 🧠 **Exam Tips**

✅ CloudFront = **global CDN** — reduces latency and improves security.

✅ Use **OAC** (not OAI) to securely connect to private S3 origins.

✅ For **API acceleration**, pair **CloudFront + API Gateway** or **ALB**.

✅ Use **Signed URLs/Cookies** for private, time-limited content delivery.

✅ Use **Lambda@Edge** (complex logic) vs **CloudFront Functions** (lightweight tasks).

✅ **Geo Restriction** for compliance or licensing requirements.

✅ Protect edge traffic with **WAF + Shield** integration.

✅ Set appropriate **TTL values** — lower TTL = fresher data, higher = cheaper & faster.

✅ Always enable **HTTPS** and manage certs in **AWS Certificate Manager (ACM)**.

## 🏁 **Real-World Example**

**Scenario:**

A video-streaming platform wants to deliver on-demand content to users worldwide with minimal latency, while preventing direct access to its S3 bucket.

**Solution:**

- Store media files in **S3** (private bucket).
- Deploy **CloudFront distribution** with **OAC** to secure access.
- Use **Signed URLs** for authenticated access.
- Integrate **AWS WAF** for filtering malicious requests.
- Monitor performance via **CloudWatch metrics** and **Access Logs**.

**Outcome:**

Global, secure, and high-performance content delivery with strong cost optimization and zero direct exposure of backend infrastructure.
